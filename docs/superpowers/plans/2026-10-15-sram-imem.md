# SRAM Instruction Memory Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 64-word flip-flop instruction memory with one IHP `RM_IHPSG13_1P_512x16_c2_bm_bist` SRAM macro (512 words), hardened in CI, with the flip-flop build kept as a parameter fallback.

**Architecture:** A new `pe_imem` module hides the single-port macro behind the old read/write interface, accepts host writes only while the core is not active and reports dropped writes through a sticky `READ_STATUS` bit; the flow places the macro with the Loom recipe (tile stripes aligned to the macro's Metal4 supply columns, no per-macro PDN grid) and a metrics gate fails the `gds` workflow on negative slack. Design: `docs/superpowers/specs/2026-10-15-sram-imem-design.md` -- read it first.

**Tech Stack:** Verilog-2005 (Yosys/Icarus/Verilator), cocotb 2.0.1 + pytest 8.4.2 via `source env.sh`, project venv (`.venv`) for tools, IHP SG13CMOS5L PDK at `$PDK_ROOT` (commit `2bbec755dc67ca3db0261c3d6163e15735d66710`, the same the Tiny Tapeout action installs), Tiny Tapeout `tt-gds-action@ihp-cmos5l` in GitHub Actions.

## Global Constraints

- Branch `sram-imem` from `main` (`ac0e555`). One commit per task; the owner is asked before any merge.
- `src/` holds only chip files: the `info.yaml` `source_files`, `isa_defs.vh`, the flow's `config.json`, and (new) the macro blackbox `RM_IHPSG13_1P_512x16_c2_bm_bist.v` and `pdn_cfg.tcl`. Nothing test-only.
- The macro blackbox is **never** in `info.yaml` `source_files` or any Makefile `PROJECT_SOURCES`; simulation defines the macro module from `test/models/`.
- Every cocotb Makefile compiles with `-DFUNCTIONAL` and both models; `-DFUNCTIONAL` is already set for `GATES=yes` in `test/Makefile`.
- `A_DLY` is tied to `1'b1` (the model `$stop`s otherwise). `A_BIST_*` all zero. `A_BM` all ones.
- Write acceptance rule: `wr_ok = wr_en && !active`; `wr_dropped = wr_en && active`; the read output **holds** during an accepted write (`A_REN = !wr_ok`); the two `IMPL` branches are cycle-identical.
- No ISA, oracle semantics, firmware or `pe_core.v` change. `isa/isa.yaml`, `src/isa_defs.vh`, `firmware/` must be byte-identical to `main` at the end (`git diff main -- isa src/isa_defs.vh firmware` empty).
- Every suite stays warning-free; `gen_isa.py --check` exits 0; Verilator lint clean.
- Tests must be shown to fail against the listed mutants (scratch copies, never committed); record which test kills which mutant in the task report.
- Run every long command in the foreground with a time limit; never hand work to a background worker or wait on a notification. Write the task report incrementally to `.superpowers/sdd/sram-task-<N>-report.md` (git-ignored).
- Vendored PDK files keep their licence headers; `test/models/README.md` names the source paths and PDK commit.

```python
async def imem_write(dut, addr, data):
    """One host write, clocked at the next rising edge (active must be 0 for it to land)."""
    dut.im_wr_en.value = 1; dut.im_waddr.value = addr; dut.im_wdata.value = data
    await RisingEdge(dut.clk); dut.im_wr_en.value = 0

async def imem_fill(dut, words):
    for a, w in enumerate(words): await imem_write(dut, a, w)

async def imem_read(dut, addr):
    """Present addr, clock once, sample both outputs after the edge."""
    dut.im_raddr.value = addr; await RisingEdge(dut.clk); await FallingEdge(dut.clk)
    return int(dut.im_rdata_m.value), int(dut.im_rdata_f.value)

@cocotb.test()
async def imem_512_words_read_back_and_alias_bit9(dut):
    """All 512 words are distinct and readable; raddr/waddr bit 9 is ignored (512+k reads k)."""
    await start(dut)
    words = [(a * 0x9E37 + 0x1234) & 0xFFFF for a in range(512)]
    await imem_fill(dut, words)
    for a in [0, 1, 63, 64, 255, 256, 511, 512 + 5, 1023]:
        m, f = await imem_read(dut, a)
        assert m == words[a % 512] and f == words[a % 512], (a, hex(m), hex(f))

@cocotb.test()
async def imem_write_while_active_is_dropped_and_reported(dut):
    """A write with active=1 changes nothing and pulses wr_dropped for exactly that cycle; the
    same write with active=0 lands."""
    await start(dut)
    await imem_fill(dut, [0x1111] * 512)
    dut.im_active.value = 1
    dut.im_wr_en.value = 1; dut.im_waddr.value = 7; dut.im_wdata.value = 0x2222
    await FallingEdge(dut.clk)
    assert int(dut.im_drop_m.value) == 1 and int(dut.im_drop_f.value) == 1
    await RisingEdge(dut.clk); dut.im_wr_en.value = 0
    await FallingEdge(dut.clk)
    assert int(dut.im_drop_m.value) == 0 and int(dut.im_drop_f.value) == 0
    dut.im_active.value = 0
    assert await imem_read(dut, 7) == (0x1111, 0x1111), "a write while active must be dropped"
    await imem_write(dut, 7, 0x2222)
    assert await imem_read(dut, 7) == (0x2222, 0x2222)

@cocotb.test()
async def imem_read_output_holds_during_a_write(dut):
    """A paused core keeps reading its stalled pc. A host write to that same address must not
    change the output register during the write cycle (no write-through); the next read cycle
    returns the new word."""
    await start(dut)
    await imem_fill(dut, list(range(512)))
    assert await imem_read(dut, 100) == (100, 100)
    await imem_write(dut, 100, 0xBEEF)                 # raddr is still 100
    await FallingEdge(dut.clk)
    assert (int(dut.im_rdata_m.value), int(dut.im_rdata_f.value)) == (100, 100), "output must hold through the write"
    await RisingEdge(dut.clk); await FallingEdge(dut.clk)
    assert (int(dut.im_rdata_m.value), int(dut.im_rdata_f.value)) == (0xBEEF, 0xBEEF), "the read after the write sees the new word"

@cocotb.test()
async def imem_macro_and_flops_agree_under_random_traffic(dut):
    """2,000 random cycles of reads, writes and active toggles: both implementations must give
    the same rdata and wr_dropped every cycle."""
    await start(dut)
    rng = random.Random(7)
    await imem_fill(dut, [rng.randrange(65536) for _ in range(512)])
    for _ in range(2000):
        dut.im_active.value = int(rng.random() < 0.5)
        dut.im_wr_en.value = int(rng.random() < 0.3)
        dut.im_waddr.value = rng.randrange(1024); dut.im_wdata.value = rng.randrange(65536)
        dut.im_raddr.value = rng.randrange(1024)
        await RisingEdge(dut.clk); await FallingEdge(dut.clk)
        assert int(dut.im_rdata_m.value) == int(dut.im_rdata_f.value)
        assert int(dut.im_drop_m.value) == int(dut.im_drop_f.value)
```

- [ ] **Step 5: Write `src/pe_imem.v`:**

```verilog
`default_nettype none
// Instruction memory, 512 x 16, synchronous read (one-cycle latency), host write port.
// IMPL = "MACRO": one IHP RM_IHPSG13_1P_512x16_c2_bm_bist single-port SRAM (the chip).
// IMPL = "FLOPS": a flip-flop array with the same cycle behaviour (fallback: a flow failure, FPGA).
// The single port is shared. A host write is accepted only while the core is not active; a write
// that arrives while the core is active is dropped and reported for that cycle on wr_dropped
// (pe_host_spi keeps it as READ_STATUS bit 5). During an accepted write the read output holds its
// previous word (A_REN low: no write-through), so a paused core's stalled instruction word is
// unchanged when RUN returns; the next cycle reads raddr again. Address bit 9 is ignored:
// addresses alias modulo 512. Contents are undefined at power-up: load before RUN.
module pe_imem #(
    parameter IMPL = "MACRO"
) (
    input  wire        clk,
    input  wire        active,
    input  wire [9:0]  raddr,
    output wire [15:0] rdata,
    input  wire        wr_en,
    input  wire [9:0]  waddr,
    input  wire [15:0] wdata,
    output wire        wr_dropped
);
  wire wr_ok = wr_en && !active;
  assign wr_dropped = wr_en && active;
  wire [8:0] addr = wr_ok ? waddr[8:0] : raddr[8:0];
  generate
    if (IMPL == "MACRO") begin : g_macro
      RM_IHPSG13_1P_512x16_c2_bm_bist u_sram (
          .A_CLK(clk), .A_MEN(1'b1), .A_WEN(wr_ok), .A_REN(!wr_ok), .A_ADDR(addr), .A_DIN(wdata),
          .A_DLY(1'b1), .A_DOUT(rdata), .A_BM(16'hFFFF),
          .A_BIST_CLK(1'b0), .A_BIST_EN(1'b0), .A_BIST_MEN(1'b0), .A_BIST_WEN(1'b0), .A_BIST_REN(1'b0),
          .A_BIST_ADDR(9'd0), .A_BIST_DIN(16'd0), .A_BIST_BM(16'd0));
    end else begin : g_flops
      reg [15:0] mem [0:511];
      reg [15:0] rdata_q;
      always @(posedge clk) begin
        if (wr_ok) mem[addr] <= wdata;
        else rdata_q <= mem[addr];
      end
      assign rdata = rdata_q;
    end
  endgenerate
  wire _unused = &{raddr[9], waddr[9], 1'b0};
endmodule
```

```python
"""Deposit a program straight into the simulated instruction memory (RTL simulations without a host).
The chip's memory is the IHP macro; its behavioural model (test/models) keeps the words in
`<u_imem>.g_macro.u_sram.i_SRAM_1P_behavioral_bm_bist.memory`. Unwritten words are set to 0 so a
simulated core never fetches X; on silicon they are random, so the host loads everything before RUN."""
IMEM_WORDS = 512

def imem_array(imem):
    return imem.g_macro.u_sram.i_SRAM_1P_behavioral_bm_bist.memory

def load_imem(imem, words):
    assert len(words) <= IMEM_WORDS, len(words)
    mem = imem_array(imem)
    for i in range(IMEM_WORDS):
        mem[i].value = words[i] if i < len(words) else 0
```

"""Fail the gds workflow on a bad hardening result. The Tiny Tapeout flow goes green on negative

import json, sys

    ("timing__setup__ws__corner:nom_slow_1p08V_125C", lambda v: v >= 0, "worst setup slack, slow corner, ns"),
    ("timing__setup__ws__corner:nom_typ_1p20V_25C",   lambda v: v >= 0, "worst setup slack, typical corner, ns"),

if __name__ == "__main__":
